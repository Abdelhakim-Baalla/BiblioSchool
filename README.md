# gestion-d-une-bibliotheque-scolaire

[Catalogue de livres simulé](https://baalla-biblioschool-demo.abdelhakimbaalla50.workers.dev/dashboard)

Le formulaire ajoute les livres au catalogue de l’onglet.

Pour reconstruire la démo depuis la racine du dépôt, exécuter `php scripts/build-demo.php`. Depuis la racine, `npx wrangler deploy` publie les fichiers générés.

[Diagramme de classes de la bibliothèque](https://github.com/Abdelhakim-Baalla/BiblioSchool/blob/main/Conceptions/ClassDiagram.svg)

BiblioSchool est une application web permettant de gérer une bibliothèque scolaire, incluant un système de réservation de livres. L'application sera construite en PHP 8 orienté objet (POO), avec une connexion à une base de données MySQL via PDO.
